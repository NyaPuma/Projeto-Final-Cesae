### Logout + auth-enforcement batch (DONE — verification pending, no `php`/`node`)
- **Bug:** `resources/js/core/auth.js` `logout()` referenced an undefined `loginUrl` in `window.location = loginUrl` inside `.finally()` → `ReferenceError`, so the redirect never ran and the session "never ended".
- **Fix:** logout now derives the login URL from `document.body.dataset.loginUrl` (fallback `/ui/login`), `.catch()`es the fetch so cleanup always runs, and `.finally()` clears `auth_token`, `api_token`, `user_name`, `user_role`, `theme`, `theme_name` from localStorage **and** expires both auth cookies before redirecting. Same cleanup applied to the secondary `utils/api.js` logout.
- Server side already enforced: all `/ui/*` pages (except `/ui/login`) live behind `Route::middleware(['custom.auth'])` (`routes/web.php:101`); `CustomAuthMiddleware` redirects unauthenticated requests to `/ui/login`. `AuthController::logout` nulls `users.api_token` + clears remember token, so old tokens are dead after logout.
