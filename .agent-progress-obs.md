## Initial Audit

- The application uses Laravel 12 with a custom exception configuration in `bootstrap/app.php`.
- The `/up` health endpoint is available for health checks.
- Logging previously defaulted to the single channel; a daily channel with fourteen-day retention was already available.
- A custom `db:backup` command already supported database dumps, compression, cleanup, and local storage.
- The scheduler already ran database backups daily and operational maintenance tasks periodically.
- Sentry, structured request context, slow-query and queue telemetry, feature flags, circuit breaking, off-site backup support, and OpenAPI generation are being added without changing existing default application flows.
- Existing OpenAPI attributes are present across the API controllers, and L5 Swagger can generate an OpenAPI 3 specification.

## Environment Variables

- `SENTRY_LARAVEL_DSN`, `SENTRY_ENVIRONMENT`, `SENTRY_RELEASE`, `SENTRY_TRACES_SAMPLE_RATE`, `SENTRY_PROFILES_SAMPLE_RATE`, and `SENTRY_SEND_DEFAULT_PII` configure optional error tracking.
- `OBSERVABILITY_SLOW_REQUEST_THRESHOLD_MS`, `OBSERVABILITY_HIGH_MEMORY_THRESHOLD_MB`, and `OBSERVABILITY_QUEUE_SLOW_JOB_THRESHOLD_MS` configure telemetry thresholds.
- `DB_SLOW_QUERY_LOG` and `DB_SLOW_QUERY_THRESHOLD_MS` configure slow-query logging.
- `BACKUP_STORAGE_ENABLED`, `BACKUP_OFFSITE_ENABLED`, `BACKUP_OFFSITE_DISK`, and `BACKUP_OFFSITE_PATH` configure backup artifacts and off-site storage.
- AWS or another configured filesystem provider must be supplied through environment variables when the off-site disk is enabled.
- `FEATURE_AI_RECOMMENDATIONS` and `FEATURE_EXTERNAL_CURRENCY_RATES` provide safe operational feature switches.

## Operational Handoff

- Set `SENTRY_LARAVEL_DSN` in the deployment secret store to enable error and performance monitoring.
- Set `BACKUP_OFFSITE_ENABLED=true` only after configuring the private S3-compatible disk and its provider credentials.
- Install `sqlite3` or `mysqldump` on the backup host according to the configured database driver, and ensure PHP has the `zip` extension for application-storage archives.
- Use `php artisan feature enable <name>`, `php artisan feature disable <name>`, and `php artisan feature clear <name>` for emergency feature control.
