| `PageControllerTest.php` | Static/public page rendering |
| `ProfileControllerTest.php` | User profile viewing and updating |
| `RegisterControllerTest.php` | Registration flow |
| `RoomControllerTest.php` | Room management pages |
| `UiControllerTest.php` | UI helper/utility endpoints |
