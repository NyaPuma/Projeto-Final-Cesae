# resources/js/components/input

> **New to programming?** See [NON_TECHNICAL_PROJECT_GUIDE.md](../../../../NON_TECHNICAL_PROJECT_GUIDE.md)

Enhanced input components with A11y support.

| File | Purpose |
|------|---------|
| `autocomplete.js` | Autocomplete with API search, abort controller, and keyboard navigation |
| `combobox.js` | Combobox with Alpine.js reactivity and API integration |
| `otp.js` | One-time password input (one digit per field, auto-focus, paste) |
| `password-strength.js` | Real-time password strength indicator (weak/medium/strong) |
| `select.js` | Enhanced select component |
