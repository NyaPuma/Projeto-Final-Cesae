# resources/js/pages/analytics

Analytics dashboard page.

| File | Purpose |
|------|---------|
| `index.js` | Main orchestrator (AnalyticsDashboard class, auto-refresh) |
| `charts.js` | Chart.js renderers for all chart types (status, trend, cost, SLA, etc.) |
| `kpi.js` | KPI and operational metrics rendering |
| `activity.js` | Activity feed and summary rendering |
| `export.js` | Async CSV/PDF export with feedback |
| `helpers.js` | Shared helpers (API calls, theme colors, messages) |
